Comment utiliser le simulateur ?

  1. Renseignez la taille du lot (quantité totale de pièces).
  2. Sélectionnez le niveau d'inspection (Général II est le standard usuel).
  3. Choisissez le NQA (Niveau de Qualité Acceptable) selon l'exigence client.
  4. Cliquez sur Générer pour obtenir le plan d'échantillonnage (Taille échantillon, Ac, Re).
